# ABOUT — The Private Room

Самостоятельная интерактивная WebGL-сцена. Она не меняет основную страницу Botanica и открывается по адресу `/about/`.

Вся графика создаётся процедурно: красные бархатные шторы, чёрно-белый шевронный пол, школьная доска на колёсах, кресла, лампы, пыль и короткие глитч-срывы.

Серо-чёрная доска имеет меловую фактуру и деревянную раму. На ней кнопками закреплены два объёмных бумажных листа:

- **Подойти** — приближает камеру к доске;
- **Осмотреться** — включает игровую камеру с ходьбой.

После приближения исходные листы сменяются меловой надписью и бумажными кнопками «Телеграм», «Гитхаб» и «Назад». Адреса находятся в объекте `contactLinks` в начале `scene.js`.

Выбор контакта запускает дверную кат-сцену с процедурным ZX Spectrum-порталом и переходом на выбранный адрес. После возврата браузерной кнопкой Back восстанавливается контактное состояние доски.

После подъёма загрузочной шторы камера коротко проходит из глубины продлённой комнаты к основной точке обзора. Камера ходьбы: `W/S` — вперёд/назад относительно горизонтального направления взгляда, `A/D` — стрейф, мышь — обзор, `Shift` — бег, `Esc` — выход. На мобильных устройствах появляются два минималистичных стика: левый отвечает за движение, правый — за обзор; маленькая кнопка `×` завершает прогулку. Высота камеры привязана к полу, при движении работает плавное покачивание шагов.

Кнопка «Телеграм» ведёт на `https://t.me/abdulkus`.

Для локального просмотра из корня репозитория:

```powershell
python -m http.server 4173
```

Затем открыть `http://localhost:4173/about/`.
